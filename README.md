## 🚀 Overview

**NATU-Students** is a next-generation mobile platform that merges **social networking** with **academic intelligence**.

It delivers a seamless experience powered by **real-time communication**, **AI assistance**, and a **scalable modular architecture**.

## 🛠 Tech Stack

| Layer            | Technology             |
| ---------------- | ---------------------- |
| Frontend         | Flutter                |
| State Management | Provider               |
| Backend          | Firebase + Supabase    |
| Database         | Firestore + PostgreSQL |
| Notifications    | FCM                    |

---

* Scalable
* Maintainable
* Clean separation of concerns

## 🔧 Configuration

Before running the project:

* Add Firebase config files (`google-services.json` / `GoogleService-Info.plist`)
* Setup Supabase URL & API Key
* Enable FCM
